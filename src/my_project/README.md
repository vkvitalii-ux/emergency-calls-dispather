# Medical Call Urgency Classifier (Классификатор Срочности Вызовов)

Проект предназначен для автоматической сортировки текстовых описаний медицинских симптомов по категориям критичности и их сохранения в базу данных.

## 📋 Функционал
- **Анализ текста**: сканирует симптомы на ключевые слова.
- **Приоритезация**: распределяет вызовы по категориям ("Критический", "Экстренный").
- **Логирование**: автоматически записывает данные в локальную базу SQLite.

## 📁 Структура проекта
- `main.py` — основной скрипт: логика классификации вызовов.
- `database.py` — модуль базы данных: создание таблиц и запись строк.
- `.gitignore` — файл исключений для системы контроля версий.

## 🛠️ Логика классификации (`main.py`)
Основная функция `classify_call(symptoms)` преобразует текст к нижнему регистру и проверяет вхождение ключевых триггеров:
- *"не дышит"* -> Критический приоритет.
- *"боль в груди"*, *"острое нарушение речи"* -> Экстренный приоритет.

## 🗄️ Схема базы данных
Программа использует SQLite. В таблице `вызовы` создаются следующие поля:
- `симптомы` (TEXT) — исходный текст обращения.
- `приоритет` (TEXT) — категория срочности.
- `бригада` (TEXT) — тип направляемой медицинской бригады.

## 🚀 Как запустить проект
Откройте терминал в папке проекта и запустите главный скрипт:
```bash
python main.py
```

## 💡 Решение проблем с терминалом в PyCharm
Если в терминале Windows PowerShell отображается предупреждение об устаревшем модуле `PSReadLine`, обновите его, выполнив команду:
```powershell
Install-Module PSReadLine -MinimumVersion 2.0.3 -Scope CurrentUser -Force
```
